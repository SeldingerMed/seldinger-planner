# Lumen blind registration regression, protocol 1

Pinned input: SeldingerMed/seldinger-lumen `79fd14d10acb96c123b37e1077214e6dbef960e4`, `lumen/registration_pack`. Use its procedural problem files only. The scorer alone opens answers after every proposal and disposition has been recorded. No fitted thresholds, reference-derived starts, trained models or operator confirmations. Do not commit exposures or run directories.

1. Run full-tree-v1, selective-a-v1, selective-b-v1 and overlap-a-v1 independently. Start model axes parallel to camera axes and model origin on the central ray at two thirds of source-detector distance; this generic depth prior is not knowledge of true depth. Also run each at +20 mm depth as a sensitivity control. Use all released medial samples, the declared intrinsics and original grayscale data. Use Planner's dark-line `vesselEvidence` and single-plane `proposeEvidenceRegistration`, detector scale fixed. Preserve score fields, failures and fitted poses unchanged. This path emits proposals for operator review, not automatically accepted registrations or calibrated probabilities.
2. Only after saving A's proposals, release overlap-b-v1 calibration and frame. Transfer each actual A estimate with the camera-to-camera transform as B's start, refine with the same single-view method on B. This tests sequential second-view evidence, not a joint two-view fit. Preserve both starting and final poses even when refused.
3. Research gate: measure the fraction of model branches supported by dark pixels. A branch is supported if at least half its sample points land within 2 px (Euclidean) of ink (grayscale <=192). Require at least 75% of branches supported, and require both depth starts to yield estimates within 5 mm whole-tree RMS of each other. Apply both checks to each estimate independently of truth, on both A and B. Preserve individual refusal reasons, including native failures. Any failed paired start prevents acceptance.
4. Independent evaluator: correct iff whole-tree RMS target error <=5 mm **and** whole-tree RMS reprojection <=5 px against released truth. Measure initial and final separately. Cross-tabulate correct/wrong by native emitted/refused and by research accepted/declined. Neither proposal emission nor research acceptance means an operator accepted the pose. Report unexpected outcomes without changing the criteria. Replay each actual input, proposal and decision before revealing its corresponding reference.
5. Acceptance requires real production-method integration, coordinate and metric tracers, contract/units/failure controls, staged blind + reveal run with reproducible receipts, and exact-head review/CI plus verified merge. No change to clinical/UI workflow.
