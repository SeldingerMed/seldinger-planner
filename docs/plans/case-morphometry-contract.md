# Case-bound mask morphometry contract

Internal engineering contract, not a clinical protocol. Fresh code in this repo only; no legacy application imports. Approved public image-only sources are server-owned and hash pinned. Original CMHA remains unknown-unit and ineligible for mm calculations. No public deployment/clinical validation is implied.

## Reconciled reconnaissance

`deleg_ef9824da` correctly identified existing plane-mesh and historical sizing helpers, but its proposed tracer is not executable as written: bottom-cap coplanar planes are rejected, a four-mm parent lies inside the historical family range, and abbreviated hashes are not valid identities. There is no existing accepted-mask mesh exporter to reuse. Segmentation metadata persistence already exists in `segmentation_state.py`; only computed geometry/dependency persistence is absent. Two parent stations require planes perpendicular to their respective local tangents, not two mutually perpendicular planes. Never derive longitudinal coverage from neck-plane Feret width, WEB average sac diameter from maximum width, or smallest sac height from a single maximum height. Do not automatically connect such surrogates to sizing.

## Numeric layers

### A. Accepted binary mask to world surface

Owned files for helper A: `planner/mask_geometry.py`, `tests/ml_runtime/test_mask_geometry.py`, `tests/test_mask_geometry_import.py` ONLY.

Implement `surface_from_mask(mask, affine, *, seed_ijk=None, reject_boundary=True)` with lazy NumPy/SciPy/scikit-image imports, no file access/model/network. Accept finite strictly binary three-dimensional array, max8000000 voxels/max100000 foreground voxels, nonsingular finite homogeneous4x4 affine. Bounds checked before marching cubes. Reject empty or wholly filled input. Optional seed: exactly3 native ints, no bool, in bounds and foreground; select its6-connected component, not an automatically chosen lesion. Without a seed use all foreground. Report original selected-component boundary contact; reject it when `reject_boundary=True`. For vessel-only local sections caller may explicitly useFalse; do not pad/truncate silently.

Run upstream marching cubes level0.5, step_size1, allow_degenerateFalse on selected-mask native XYZ grid, no smoothing/decimation. Transform vertices with the full affine once, including reflected anisotropic/oblique axes. Max50000 output triangles (reject oversize before Python triangle-soup materialization). Return JSON-compatible dict: `triangles_world`, `foreground_voxels`, `touches_image_boundary`, `method='native_binary_marching_cubes_0_5'`, `clinical_validation=False`. Registration to anatomy/annotation is not established by this transform. Synthetic tests independently prove half-voxel boundary coordinates, asymmetric shape/index/seed selection, oblique reflected affine mapping, guards and import laziness; no actual image/model reads.

### B. Plane contour selection and clipped sac metrics

Owned files for helper B: `planner/morphometry_selection.py`, `tests/test_morphometry_selection.py` ONLY. Stdlib only. Do not modify existing geometry helpers/tests.

Implement `selected_section_metrics(triangles, origin, normal, *, spatial_units='unknown')`. Preserve existing cap/finite/degenerate/coplanar/open/branched rejection rules. Partition plane intersections into all closed loops, select EXACTLY ONE whose projected polygon strictly contains the plane origin (operator-supplied lumen point); reject zero or multiple containing loops and points on boundary. Other closed disjoint loops must not be silently measured. Return existing section_metrics shape plus `selection='unique_contour_containing_operator_origin'` and plane origin/normalized normal. Area/Feret come from the selected polygon, not arbitrary nearest loop or centroid. Return clinical validationFalse.

Implement `clipped_sac_metrics(triangles, neck_origin, neck_normal, *, spatial_units='unknown')`. Positive normal is operator-selected dome side. Height=max perpendicular positive vertex distance. Width=max planar Feret of the mesh clipped to closed positive half-space, including vertices on plane and true edge-plane intersections, NOT only strictly positive original vertices. Deduplicate exact geometric points before4096-point cap; still max50000 triangles, reject absent positive dome or invalid points. Return height/width, units, method='operator_plane_clipped_surface', validated_morphometryFalse and discretization_limitedTrue. Preserve old helper behavior by not editing it. Analytic hemisphere/equatorial width test must distinguish old strictly-positive-vertex bias. No anatomical neck validation.

## C. Parent-owned API/runtime/persistence

Client supplies only case version, source revision, explicit neck origin/normal, aneurysm seed RAS, bounded operator parent path RAS and two distinct interior indices. No paths, triangles, mask hashes or source IDs from request. Source metadata and current accepted vessel/aneurysm identities are server selected. Local tangent at a station is path[i+1]-path[i-1]. This is an operator-defined path, not extracted/validated centerline.

PUT `/api/cases/{id}/morphometry-inputs` persists the bounded operator configuration and advances the case revision before computation. POST `/api/cases/{id}/morphometry` consumes that saved configuration and an exact case/source snapshot; it must not mix unsaved client inputs with an older result. Computation uses the fixed isolated ML runtime with timeout60s, bounded inputs/outputs, clinical flagsFalse. Validate source mm geometry and mask hash/native shape/affine/units/binary in worker. Choose aneurysm component using explicit foreground seed; require it interior to image. Parent stations must sample vessel foreground. Use a vessel component containing a parent station and require every supplied path sample to lie in vessel foreground on that same6-connected component. This deliberately refuses unsupported mask gaps rather than fabricating a supported centerline. The two station positions must be physically distinct (1e-9mm equality tolerance), not merely different indices. Zero local tangents are rejected. Closed sections contain their operator origins. Return sac, neck, proximal/distal section estimates, contours, plane definitions and exact dependencies. No automatic sizing in this layer.

Persist separately in a new typed geometry table, not the point-pair measurements table. Bind case/image/source revision, BOTH accepted candidate IDs/mask hashes/segmentation revisions, operator-input hash and exact calculation version. Compute outside DB transaction; transactional persistence must recheck source dependencies and expected case revision. GET current geometry reads live dependencies, suppresses ALL numeric results when stale (preserve old evidence internally). Mask replacement/SAM acceptance, source or operator input change must never serve previous numbers/sizing as current. Rejected previews preserve valid geometry. Persisting a result should not invalidate itself. Case revision mismatches conservatively invalidate pending computations; no stale numeric result may be returned from a racing write. Endpoint runner is injectable for CI-safe analytic tracer tests, but actual public-mask execution is required before completion.

## Acceptance ceiling

Analytic numerical verification and native-mask/source geometry consistency are software evidence, not validated clinical sac/neck boundaries or device suitability. No STLs from public annotations are used. Original reference surfaces remain unregistered. Do not claim full-head localization or segmentation accuracy. Final slice requires actual approved case computation and browser evidence, persisted reload and real invalidation of previously materialized numbers, plus full tests/lint/build.
