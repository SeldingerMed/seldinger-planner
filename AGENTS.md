# Seldinger Planner

New CTA-first intracranial aneurysm planning application. This is a fresh implementation. Do not clone, cherry-pick, copy files/snippets/assets/tests/configuration/models, or import application code from legacy repositories into this repository. Reuse ideas only; author code from the new contracts and upstream library documentation. Install libraries directly from upstream packages. Obtain public demonstration data independently from its original source and keep it out of git. Any later owned-model integration requires its own original-artifact provenance contract, not a legacy-repository import. Preserve the old app and ML worktrees.

Follow the Hermes-native engineering harness and test-driven development. Never use OMP. No patient/partner data, model weights, credentials, or bulk generated artifacts in git. Never read or print .env during ordinary code review. Secrets belong only in ignored .env (0600), never in frontend environment variables or config files.

Distinguish trained inference, curated annotations, clinician edits, synthetic fixtures, and cached outputs. No automatic aneurysm-detection or clinical-validity claims without measured evidence. Every future case tool must bind to server-selected case identity and artifact version. Never give the product agent shell access or arbitrary filesystem/URL tools.

Current slice: browser-local CTA viewer, revision-bound manual evidence/notes, an operator-entered aneurysm worksheet with bounded, source-backed Muse discussion, and a hash-checked original-public-case curated 3D reference preview. Reference surfaces are not inferred segmentations or slice-wise contours. Their coordinate transform remains a candidate, and source units remain unspecified. This is not a validated clinical planning application. Images are not included in workspace/model write requests. Clinical suitability, calibrated morphometry, device sizing, segmentation inference and SAM correction are not established. No external deployment is authorized by this file.
